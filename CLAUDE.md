# Instruções para o Claude Code

- Este é o site da CQT Sistemas da Qualidade
- Sempre que fizer qualquer edição em arquivos, faça automaticamente git add (só dos arquivos alterados, nunca `-A`) e commit com mensagem descritiva em português. Push para o GitHub só quando o Leandro pedir.
- O site está hospedado no GitHub Pages em https://leandrocentomo-arch.github.io/cqt-site/
- Mantenha todos os textos em português com acentuação correta
- As imagens ficam na pasta img/
- O CSS principal fica em css/style.css

## Identidade CQT (desde 08/11/2026)

- Marca: só logos da CQT (`img/CQT_Logo_Red_White.svg`, `CQT_Logo_Regular.svg`, `cqt-selo-servicos.png`). Nenhuma logo ou texto da Ideal Metrics no site.
- Tipografia: Roboto Slab nos títulos, Roboto no corpo, Roboto Mono em rótulos e botões. Exceção: a seção «Serviços de destaque» da home é cópia fiel da seção do site no ar (cqt-br.com) e usa IBM Plex Sans Condensed.
- Cores: vermelho `#EF4545` como acento, grafite `#3D394A`, cinza-azulado `#50687B`.
- Estilo visual diferente do site Ideal Metrics: sem losango, sem pássaro, sem trama Bayer azul nas fotos.
- Home: as quatro lâminas do topo (Certificação ISO, Inspeções de Qualidade, Sustentabilidade ESG, Segurança Alimentar) ficam como estão.

## Texto

- Voz institucional: sem «você», sem «sua empresa».
- Título é rótulo descritivo: sem slogan, sem contagem, sem construção «da X à Y».
- Sem metatexto («o quadro abaixo mostra»).
- Sem número que não tenha fonte (projetos entregues, clientes atendidos, taxa de aprovação).
- A CQT implanta e prepara para a certificação; não certifica.
